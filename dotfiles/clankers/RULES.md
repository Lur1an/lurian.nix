# Source Research

When researching a public GitHub repository, prefer the DeepWiki MCP tools for
architecture, documentation, and source-code questions.

Fall back to the repository source, official documentation, or web research
when DeepWiki has not indexed the repository, appears outdated, or exact
line-level verification is required.

# Worktrees

Whenever the user requests a worktree, load and follow the `treehouse` skill.
Use Treehouse to allocate and enter it, work inside it, and return it when the
task is finished.
